# GAME2014 Assignment 2

**A mobile platformer coursework project** with main-menu flow, level selection, parallax background, 2D movement, and a simple game-state manager.

---

## Status

Team/course assignment snapshot. Educational work.

## Tech stack

| Area | What it uses |
|---|---|
| Engine | **Unity 2022.3.45f1** |
| Language | **C#** |

## What's in the project

| System | Key files |
|---|---|
| Game state singleton | `Assets/Scripts/StaticManagers/GameManager.cs`, `SingletonGeneric.cs`, `GameController.cs` |
| Menus / level select | `Assets/Scripts/MainMenu/`, `Assets/Scripts/Gameplay/LevelSelector.cs` |
| Movement / parallax | `Assets/Scripts/Gameplay/Movement2D.cs`, `ParallaxBackground.cs` |

Course assignment archive (`OzcanAlmeidaAsci` naming reflects the team). Not a production release.
